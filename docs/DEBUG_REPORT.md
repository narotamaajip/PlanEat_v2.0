## Setup & Leftover Data Note

- **Port 8000 dual-stack note:** On macOS, if another local service is bound only to IPv4 `127.0.0.1:8000`, `python3 -m http.server 8000` binds to IPv6 `[::]:8000` without raising `EADDRINUSE`. Opening `http://localhost:8000` resolves to `::1` and serves PlanEat, whereas `http://127.0.0.1:8000` hits the IPv4 listener. Furthermore, `config.js` restricts the Firebase browser API key to `http://localhost:8000/*`, so `http://localhost:8000` must always be used.
- **Clean profile vs. Leftover data (`planeat.v1`):**
  - In a **clean browser profile / incognito window**, `localStorage.getItem('planeat.v1')` is `null` and the app boots directly into the **7-step Onboarding (`Welcome to PlanEat`)** via `if (store.targets && store.profile) renderMain(); else renderOnboarding();` (`app.js:1691`).
  - If `localStorage` already contains `planeat.v1` (or legacy `fuelly.v1`) with `targets` and `profile` populated from a previous session, the app skips onboarding and opens **straight on the Dashboard (`.shell`)**. Clearing site data (`localStorage.removeItem('planeat.v1')`, unregistering service workers, and deleting Cache Storage `planeat-shell-v3`) and reloading restores the onboarding flow.
  - Because there is no Settings/Reset UI yet (`docs/MIGRATION.md` §1 #5), users with existing `planeat.v1` data have no in-app button to re-run onboarding or edit targets without clearing browser site data.
- **App Check on `localhost`:**
  - Without `localStorage.getItem('planeat.debugToken')`, `ReCaptchaEnterpriseProvider` attempts to run against `http://localhost:8000` (which is not an allowed domain on the production reCAPTCHA Enterprise key `6Lc69hIuAAAAAGNUjjrxgzICTdUvRazB1QvbMafE`) and logs:
    `[warn] @firebase/ai: Unable to obtain a valid App Check token: AppCheck: ReCAPTCHA error. (appCheck/recaptcha-error).`
  - Because App Check enforcement is **not** switched on yet in Firebase Console (`HANDOFF.md` §Security), `POST https://firebasevertexai.googleapis.com/v1beta/projects/planeat-alpha-2/models/gemini-3.5-flash-lite:generateContent` **still succeeds with HTTP `200 OK`**. Once App Check is enforced, `localhost` will require `localStorage.setItem('planeat.debugToken', '<token>')`.
